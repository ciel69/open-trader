Аудит: `./tb audit-public` (только чтение, значения секретов не печатаются; `--json`, `--strict`, `--term СЛОВО`, `--root ПУТЬ`). Код возврата 1 при находках high/medium.

## 2. Что исправить владельцу
1. Личные пути: `docs/QUICKSTART.md:3` (cd с вашим путём), `docs/GATEWAY.md:70,74` (команды `claude mcp add` с абсолютным путём), `docs/ref/ai_trader_review.md:3` (путь временной папки сеанса). Замените на `<путь к репозиторию>` / `$PWD`.
2. `config/agents.json`: содержит хеш токена агента `api` (SHA-256, не секрет, но личный). Перед публикацией использовать `examples/config/agents.json.example` (хеши null) вместо реального файла: `cp examples/config/agents.json.example config/agents.json` ТОЛЬКО в чистой копии для публикации, не в рабочей папке (платформа работает). Либо исключить реальный файл из git и положить в репозиторий пример.
3. Фикстуры с «врагами» (`tests/fixtures_intel`, `fixtures_roles`) содержат поддельные ключи и адреса намеренно: убедитесь, что они выглядят заведомо поддельными (`sk-` + осмысленное слово), при желании пометьте.
4. `docs/spec_v2/STATUS.md` и `docs/BACKLOG.md` содержат живые журналы работы и размеры вашего счёта (например «~39 USDT»); решите, оставлять ли их (честная история) или сократить.
5. `.DS_Store`, `__pycache__/`, `*.lock`: скрыты `.gitignore`.
6. Метка автора коммитов: проверьте `git config user.name/user.email` ПЕРЕД первым коммитом (иначе в историю попадёт личная почта).

## 4. Что решить владельцу
- **Сторонние ссылки и материалы**: `docs/ref/deepseek_api.md`, `docs/ref/landscape.md`, `docs/ref/ai_trader_review.md`, раздел 1 `docs/DESIGN_V2.md` разбирают сторонние проекты (в т.ч. HKUDS/AI-Trader: маркетинг против подтверждённого, оценка безопасности). Риски: пересказ чужой документации (лицензия), критические оценки чужого проекта без надёжной проверки (в самом разборе сказано, что исходники не читались), ссылки на баг-трекеры сторонних проектов. Предложение: убрать прямые ссылки на трекеры, оставить нейтральные описания и ссылки на официальные страницы, а `ai_trader_review.md` не публиковать или сократить. Без согласования не правил.
- **Язык документации**: документы на русском, README и ключевые файлы на английском. Оставить или переводить постепенно (предлагаю оставить, указано в README).
- **Название**: репозиторий `open-trader`, пакет и команда `tb` (`./tb`), каталог ключей `~/.config/traider-bot/`. Возможна путаница; решите, переименовывать ли каталог ключей позже (сломает существующие установки), я не трогал.
- **Контакт в `SECURITY.md`**: стоит плейсхолдер `<ВПИШИТЕ КОНТАКТ>`; заполните или включите GitHub private vulnerability reporting. Контакт также упомянут в `CODE_OF_CONDUCT.md` через `SECURITY.md`.
- **Права и текст про деньги**: в `docs/QUICKSTART.md` и `docs/spec_v2/*` есть ваши размеры счёта и даты; просмотрите.
- **Документы только для вашего агента**: `CLAUDE.md` обезличен и остаётся; `docs/PERMISSIONS.md` ссылается на ваши настройки Claude Code: оставить как пример.
- **Подписи коммитов и бейджи**: решите, нужен ли CI (сейчас нет; тесты запускаются локально `./tb test`).

## 5. Порядок публикации
1. Остановить правки дашборда и параллельных пакетов (WP15b и др.); зафиксировать состояние.
2. Сделать ЧИСТУЮ копию проекта в другую папку (без `state/`, `runtime/`, `data/`, `.claude/`, `CLAUDE.local.md`); публикацию вести из неё, рабочую папку и работающую платформу не трогать.
3. В копии применить п. 2 и п. 3 (примеры вместо личных файлов, личные пути).
4. `git init`; проверить `.gitignore` (`git status --ignored` должен показывать `state/`, `runtime/`, `data/` как игнорируемые); проверить `git config user.name/email`.
5. `./tb audit-public` в копии: high 0, medium 0; `./tb test` зелёный.
6. Первый коммит (`git add -n .` сначала, просмотреть список файлов).
7. Создать ПРИВАТНЫЙ репозиторий на GitHub, запушить, посмотреть в веб-интерфейсе, поискать по репозиторию свои имя, почту, путь, токены.
8. Включить Secret scanning / push protection, private vulnerability reporting.
9. Только потом сделать репозиторий публичным; в описании продублировать отказ от ответственности.
