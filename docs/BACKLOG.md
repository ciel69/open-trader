СДЕЛАНО 2026-10-27 [A]** (net RR = (тейк% - издержки) / (стоп% + издержки) >= min_rr; размер считается от стопа плюс издержки; издержки по площадке в `config/risk_profile.json:costs`).    54% (scalp 0.8%), 51% (1%), 44% (3%). `min_rr` в профиле считается до издержек. Предложение: `guard` отклоняет сделку, если (tp% - издержки) / (stop% + издержки) < min_rr; тест: набор сделок на границе.
