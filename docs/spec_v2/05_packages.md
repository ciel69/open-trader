# SPEC V2 / 05. Пакеты работ WP0..WP11

Часть `docs/SPEC_V2.md`. Для субагентов: каждый пакет самодостаточен, владеет ПЕРЕЧИСЛЕННЫМИ файлами (множества не пересекаются), пишет против `06_contracts.md` и `01..04`, не трогает чужие файлы (нужна правка в чужом файле = запрос ведущему). Репозиторий не под git: в отчёте каждый агент перечисляет созданные и изменённые файлы. Общие требования ко всем: Python 3.9, только stdlib; кроссплатформенность (нет `fcntl`/`os.fork`, пути через `paths`, `fsutil.replace`, `encoding="utf-8"`); комментарии и docstring по-русски; стиль соседнего кода; без сети и без `~/.config/traider-bot/*` в тестах; запрещено вызывать `./tb bybit ...`, торговать, запускать демоны вне тестов; перед сдачей `./tb test` зелёный (прежние ~560 тестов не меняются по поведению). Оценки в агентских днях (1 день = связная сессия субагента среднего размера).

Фаза A (клиент, 3 дня):

Монотонность стопа проверяется ЗДЕСЬ тоже (читает текущий стоп перед записью; новый не строже = `PortError(rejected, STOP_NOT_TIGHTER)` без вызова биржи). Округление цен/количества по tick/qtyStep через существующие `step_floor/step_ceil`. Правило для ПОДТЯГИВАЕМОГО стопа: округление идёт в сторону ужесточения (long: вверх, short: вниз), чтобы округлённый стоп не оказался слабее запрошенного и слабее текущего; результат сравнивается с текущим стопом ПОСЛЕ округления (равный = `unchanged`), и проверяется зазор до last/mark (стоп не должен срабатывать мгновенно: иначе `STOP_ON_WRONG_SIDE`). Для начального стопа входа остаётся прежнее правило `bybit_limit` (стоп отодвигается от входа, размер посчитан guard с учётом округления). Вход: `03`, `06` п. 6.6, схема плана WP2, хранилище WP4 (для CLI; `bus` независим).
Состав: `bus` (emit/read/курсоры delivered/acked/sanitize/ротация/блокировка), `plan_cli` (все подкоманды 3.1; запись только через `PlanStore.inbox_put`; `--wait` опрашивает `_outbox`; `plan check` оффлайн по `runtime/instruments.json`, `prices.json` и `guard.evaluate` с `no_session`), `events_cli` (`--follow` с `--redeliver`, синтетический `exec_down`, ack), `brief` (режимы start/event/plan, лимит токенов `--budget-tokens` приблизительно через число символов/3.5, белые списки полей, сохранение в `state/briefs/`).
Тесты (ориентир 70): белый список (злонамеренные строки в `hot_events.jsonl`, `ideas.jsonl`, названиях символов, `thesis` с инструкциями и управляющими символами не попадают в `brief` кроме `own_thesis` с обрезкой; тест-«инъекция»: известные фразы `ignore previous instructions` в любом внешнем поле → отсутствуют в выводе), токен-бюджет (усечение с `trunc:true`, порядок приоритета блоков), курсоры (доставка at-least-once после «падения» между delivered и ack), ротация, конкурентные `emit`, `plan submit` когда исполнитель «мёртв» (`queued`), идемпотентность повторной отправки, форматы ответов 3.1, чистота зависимостей (нет импорта `tb.venues`/`tb.executor` в `tb.brain`), `plan list/show` читают файлы исполнителя без блокировок и переживают частичные папки.
Готово: `brief` на фикстурах реальных форматов (`runtime/hot.json` и т. п.) укладывается в бюджет; `events --follow` проверен интеграционным тестом на подпроцессе (читает растущий файл).
Testnet: нет (полностью локальные файлы).

## WP10. Документация, миграция, e2e, runbook, права (3 дня)
Файлы: `docs/ARCHITECTURE.md`, `docs/HARNESS.md`, `docs/PERMISSIONS.md`, `docs/BACKLOG.md`, `docs/WINDOWS.md` (правки), новые `docs/spec_v2/runbook.md` (запуск, launchd/Task Scheduler, чек-лист фаз миграции), `docs/spec_v2/claude_md_patch.md` (предлагаемые правки `CLAUDE.md` для применения владельцем; сам `CLAUDE.md` и `TRADING.md` агент не меняет), `tests/test_e2e_plan_flow.py`, `tests/test_e2e_brain_flow.py`.

Права: рекомендованный набор правил `allow/ask/deny` для `./tb plan|brief|events|exec|exp` (PERMISSIONS.md).
Готово: документы согласованы с кодом (команды из docs реально существуют и их справка совпадает), runbook проходится «вхолодную».

## Правила взаимодействия агентов
- Контракты (`06`, `01`) меняет только ведущий; агент, нашедший ошибку/пробел в контракте, пишет в отчёте «контракт: ...» и делает минимально совместимое решение в рамках своих файлов.
- Файлы чужих пакетов не править даже ради очевидной ошибки: сообщить ведущему.
- Каждый агент в отчёте: список файлов, число новых тестов, `./tb test` результат, что НЕ сделано/не проверено, найденные расхождения с документацией Bybit.
