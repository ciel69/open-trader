## Объём + свеча после импульса (2026-10-27, `research/research_volume.py`, `./tb research volume`)
Вопрос владельца: предсказывает ли объём отскок или продолжение? Ответ на 5м свечах Bybit: НЕТ, edge не найден ни в одной из 24 проверок; торговать по этому нельзя.
- Данные: `./tb bybit read klines --top 100 --interval 5 --days 40` -> `data/klines/k5_<SYM>.csv` (74 МБ, манифест `manifest_k5.json`): 100 самых ликвидных USDT-перпов по turnover24h без BTC/ETH/SOL, 1.15 млн свечей, 2026-09-17 .. 2026-10-27 (у CT меньше истории). Вердикт даёт группа crypto (72 монеты, 826 тыс. свечей); 28 токенизированных акций/ETF/металлов/нефти (`klines.STOCK_LIKE`) идут справочно.
- Правила зафиксированы в докстринге модуля до первого прогона. Импульс: 5м тело |close/open-1| >= 1.0%, vm = объём / медиана за 24 ч, cp = положение закрытия в диапазоне. Гипотезы K_H=6: V1 vm>=3 + закрытие в стороне импульса -> продолжение; V2 vm>=3 + закрытие в противоположной трети -> откат; V3 vm<1 -> откат; V4 vm>=3 + 3 бара падающего объёма -> разворот; V5a/V5b vm>=10, вход через 3 бара против/по импульсу. Выходы: 15/30/60 мин и SL (стоп 1.5 ATR, тейк 3 ATR, макс. 60 мин; стоп первым). K = 6 x 4 = 24, поправка Бонферрони. Издержки: taker круг 0.24%, maker-вход оптимистично 0.156%. SE по кластерам «день входа». Нули: по импульсу/против/случайно на тех же импульсах без фильтра объёма. Train = первые 60% (до 2026-10-12), test = 16 дней, 3 части.
- Результат на test (crypto, taker, net на сделку): V1 -0.23..-0.34% (n 2.8-4.3 тыс., PF 0.78-0.81, t_cl до -4.4); V3 -0.11..-0.22% (n 1.0-1.5 тыс.); V4 -0.16..-0.34% (n 1.2-1.4 тыс.); V5a -0.28..-0.64%; V5b -0.08..+0.16% (при 60 мин +0.16%, PF 1.13, но первая часть test -0.28%, на train -0.54%: нестабильно). Валовая доходность почти везде около нуля (|gross| < 0.15%, у V5a/V5b на 60 мин +-0.4% с противоположными знаками на train и test): объём не даёт направленной информации, издержки 0.24% всё съедают. Нулевые модели также отрицательны (-0.07..-0.41%), то есть голый импульс без фильтра тоже убыточен.
- V2 (длинная тень против импульса при vm>=3): единственное, что выглядит положительно (train +0.64/+1.31% на 30/60 мин, test +0.79/+0.72%, PF 1.2-1.3), но n = 71-81 на разбиение, всего 17 монет, t_cl около 0.6-1.0, p_adj = 1.0, n<100 (правило недостижимо по построению: тело >=1% и закрытие в противоположной трети требуют диапазона >=3%). Это гипотеза для проверки на более длинной истории, а не сигнал. Справочная группа stock: 0 из 24; V2 там n=1.
- Вердикт: edge НЕТ (0 из 24 по критерию пользователя, 0 строго с поправкой K). Критерий: test net>0, PF>=1.3, n>=100, лучше всех нулей, плюс в 2 из 3 частей test.
- Ограничения: 40 дней и один рыночный режим (16 дней test, около 16 независимых дней: события коррелированы между монетами), выживание (текущие ликвидные монеты), 5м свеча не показывает порядок high/low внутри бара, проскальзывание 0.02% занижено для малых монет, funding не учтён, импульс только одной свечой (серии из 3 свечей и пороги X, m не варьировались, чтобы не раздувать K).
- Дальше (если вообще продолжать): V2/«отвержение» на 6-12 месяцах 5м данных и на 1м-тиках входа; объём как фильтр режима (не как сигнал); maker-вход требует модели заполнения, иначе оценка оптимистична. Не повторять простые правила «объём x свеча» на тех же данных.
